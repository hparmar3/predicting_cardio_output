# Predicting Cardiac Output from Arterial Blood Pressure
## Overview
This project investigates the estimation of cardiac output (CO) and total peripheral resistance (TPR) using arterial blood pressure (ABP) waveforms. The goal is to explore computational approaches for estimating important cardiovascular parameters non-invasively using routinely collected physiological measurements.

Using patient data from the MIMIC II database, this project implements and evaluates multiple cardiac output estimation algorithms, examining their ability to estimate continuous cardiac output from material blood pressure signals.

## Background
Cardiac output is a key measure of cardiovascular function, representing the volume of blood pumped by the heart per minute. Although clinically important, direct measurement of cardiac output often requires invasive procedures, such as thermodilution.

Arterial blood pressure waveforms provide an opportunity to estimate cardiac output through computational models of the cardiovascular system. This project explores these methods using the Windkessel model, which represents the arterial circulation through its resistance and compliance properties.
